# Браки и обратная связь МСП

Читать `references/DEFECTS_FEEDBACK_CATALOG_20261112.md`.
Использовать две согласованные вкладки; жалобы считать только по основной,
вкладка Лазера дополняет статусами и не увеличивает число обращений.
Сначала проверить свежесть last-success.json и last-attempt.json в
`/opt/mcp/data/msp/defects-feedback/`.
По SKU сначала найти внутренний артикул и кабинет в product_listing.
Рабочий вход: `python3 /home/hermes/.local/share/msp-defects-feedback/sync.py query --article INTERNAL_ARTICLE`.
Не приписывать жалобам звёздность, не считать статус независимым доказательством
исправления и не смешивать дату поступления с датой покупки/публикации.
Подробная схема, категории, ограничения и ежедневное обновление — в справочнике.
