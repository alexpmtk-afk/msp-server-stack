# МСП Самовыкупы — журнал решений и отклонений от первоисточника

**Этот файл можно дополнять.** Исторические документы в приватном `msp-server-bridge/docs/self-purchases/original/` не редактировать. Новые решения не записывать как будто они прозвучали на исходном совещании.

## Правила записи

Каждое решение: дата/время, ID, инициатор, исходный ориентир, суть изменения, почему, данные/доказательство, эффект для формул/кода, статус утверждения и ссылка на реализацию/тесты.

Метки: `proposal` (предложено), `approved` (утверждено пользователем), `implemented`, `verified`, `rejected`. Не приравнивать merged PR к доказательству работоспособности REMOTE.
