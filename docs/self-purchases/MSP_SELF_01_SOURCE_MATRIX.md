- `wb_sku(report=by_period)` в том же опыте: **NO_JSON_PAYLOAD**; наличие исторического рейтинга/дневных отзывов через текущий MCP не доказано. В официальном интерфейсе MPSTATS дневные графики описаны; возможности конкретного MCP-метода нужно проверить отдельно. Источник: [приватный №514](https://github.com/alexpmtk-afk/msp-server-bridge/issues/514).
- По ограниченному отбору из локального реестра: минимум 20 WB кейсов с полноценными 7/14-дневными окнами, **ни одного Ozon кейса** при этих критериях (не путать с отсутствием SKU Ozon в каталоге).
- Google-выгрузка продаж остаётся **опциональной сверкой** и не является блокером MPSTATS-first этапа.
