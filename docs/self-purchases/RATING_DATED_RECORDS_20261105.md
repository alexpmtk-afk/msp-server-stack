## Команда

`python3 /home/hermes/.hermes/skills/productivity/msp-self-purchases/scripts/msp_rating_history_cli.py --marketplace wb --sku SKU --from YYYY-MM-DD --to YYYY-MM-DD`

Для структурированного результата добавить --json. Для Ozon — --marketplace oz.
Даты проверять: последние N завершённых календарных дней по Москве; конец вчера.
Для анализа относительно собственного отзыва отдельно передать --review-date
из реестра и другие --own-review-date; не подменять её датой покупки.
Для обычного заданного периода дата собственного события не требуется.

## Что делает проверенный способ

1. MPSTATS MCP: account_limits, затем wb_sku/ozon_sku с comments и by_period.
   Фильтр периода для comments локальный; dates/valuation независимо от текста.
2. Дневные снимки и отдельные оценки хранятся и показываются раздельно.
3. Для WB при нуле полученных записей в окне или недоступной выборке:
   получить фото-адрес из wb_sku(full), строго проверить SKU и адрес,
   прочитать card.json, сверить nm_id, взять imt_id. Через
   feedback-bt.wildberries.ru получить разрешённый адрес ленты, затем
   feedbacks/v2/imt_id. Отобрать точный nmId внутри объединённой карточки.
4. Прямой источник неофициальный и неполный. Его записи с ID не объединять
   арифметически с анонимными строками MCP: иначе возможен двойной счёт.
   Выводить отдельно источник, даты, звёзды, число строк и последнюю дату.
   Даты прямого источника переводятся из UTC в Europe/Moscow.
5. Кэш last_request, дата updatedDate старого отзыва и день изменения
   счётчика НЕ заменяют createdDate/date публикации. При неизвестных звёздах
   написать «не установлены», а не вычислять их из изменения среднего рейтинга.
6. Лимит MPSTATS 24, включая account_limits и получение full.
   Прямое чтение ограничено тремя существующими запросами, без записей,
   новых кабинетов, платных сервисов и изменения проектов наблюдения.

## Формат результата

- Площадка, магазин, точный артикул и запрошенный период.
- Рейтинг карточки в начале/конце и дробный показатель отдельно.
- Таблица всех найденных дат и звёзд, включая записи без текста.
- Распределение 1–5 и средняя найденных; собственные записи отдельно.
- Источник, свежесть и ограничение полноты одной ясной фразой.
- При пустом окне: сколько исходных строк получено и какая у них последняя
  дата; результат проверки прямой ленты; счётчики отдельно от публикаций.
  Не выдавать старые строки за новые и не менять 60 дней на 30 молча.


## Почему рейтинг может измениться без новых видимых отзывов

Различать три факта: датированные записи отзывов, опубликованный рейтинг WB
и наблюдаемый показатель MPSTATS. Рост одного из них не доказывает появление
новых пятёрок. По официальной инструкции WB старые оценки теряют вес;
после модерации/изменения отзыва может измениться состав учитываемых оценок.
Это возможные объяснения, а не установленная причина по конкретному SKU.
Изменение дробного поля commentsvaluation MPSTATS обозначать именно как
наблюдение источника, пока оно независимо не сверено с WB на те же даты.

Если владелец проверил отсутствие новых отзывов в карточке, сохранить это
как отдельное свидетельство владельца с указанным периодом. Не объявлять
по одному осмотру полноту всех скрытых/голых оценок или истории удалений.
Не называть причиной самовыкупы, удаление или затухание без доказательств.
Для установления причины нужны сопоставимые исторические составы оценок,
статусы включения и история изменения показателей; при их отсутствии
сказать «точная причина изменения рейтинга не установлена».

Официальная инструкция по рейтингу товара:
https://seller.wildberries.ru/instructions/ru/kg/material/item-rating-kg

## Подтверждение и граница

Способ действительно даёт датированные звёзды на карточках, для которых
источник возвращает такие строки. Повторная проверка 05.11.2026 включала
целевую карточку и ранее успешную контрольную карточку. Для целевой карточки
оба источника отдали только старые записи, тогда как счётчик изменялся недавно.
Это подтверждённое ограничение источников на этой карточке, не доказательство
нулевого числа новых оценок и не обещание универсальной полноты.

Полный источник голых оценок может потребовать отдельного разрешённого доступа
продавца. Официальный список WB имеет createdDate и productValuation,
пагинацию и обработанные/необработанные записи; оценки без текста относятся
к обработанным. Архив проверяется отдельно. Наличие документации не означает,
что доступ уже подключён или успешно испытан. Не просить кабинет как условие
частичной внешней статистики, но не скрывать его необходимость для ещё
неподтверждённого полного маршрута.
