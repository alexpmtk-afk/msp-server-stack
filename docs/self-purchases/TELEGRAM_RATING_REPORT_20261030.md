# Оценки в основном отчёте и сбой Telegram — 30.10.2026

Обычная команда `msp_self_sku_report_cli.py --sku SKU` теперь обязательно
вызывает новый источник звёзд WB/Ozon. Отдельный запрос к рейтинговому
помощнику для включения этого раздела больше не требуется.

Для каждой зарегистрированной даты показываются рейтинг накануне, последний
доступный рейтинг с датой, числа найденных 1–5★ и средняя ДО/ПОСЛЕ.
Сравниваются точные завершённые окна действующего планировщика; разрывы
между базовым ДО и текущей датой серии не относятся к ДО. Записи всех
собственных дней отложены отдельно. Источник не доказывает полноту или
независимость покупателей; опубликованный рейтинг не очищается вычитанием 5.

На звёзды выделяется бюджет раньше необязательных метрик заказов и цен.
Общий предел — 24 чтения, включая квоту. Пропуски/нехватка бюджета означают
«неизвестно», не ноль. Последний снимок ищется за 90 завершённых дней;
его реальная дата показывается явно, прошлый контроль не выдаётся за «сейчас».

Если самовыкупов/даты отзыва в реестре нет, программа не падает: показывает
доступную историю оценок за последние 90 завершённых дней и запрашивает
дату для сравнения. Дата покупки или пример из другого чата не подставляются.
Отсутствие записи не превращается в отказ от доступных внешних данных.

## Установка и проверка

`python3 scripts/install_msp_rating_report.py --source-commit SHA40`
закрепляет основной вход на точном коммите и экспортирует связанные модули
в отдельную папку. Предыдущий вход сохраняется, файлы сверяются SHA-256.
Активная версия: `~/.local/share/msp/rating-report/active-manifest.json`.
Установщик не перезапускает службы и не меняет SQLite или маркетплейсы.

Проверки `test_msp_telegram_rating_report.py` охватывают основной WB/Ozon
маршрут, отсутствие реестра, звёзды без текста, свои даты, последний снимок
и исчерпание бюджета. Проверка модели/доставки Telegram учитывается отдельно.

## Отдельная причина остановки фоновых запросов

Квитанции рабочего процесса показали отказ до исполнения модели:
`Unsupported gateway CLI options: --no-restore-cwd, --run-budget`.
Общий CLI help перечислял эти параметры, но действующий путь gateway их
отклонял. Из вызова worker удалены оба; `--in` и контроль времени дочернего
процесса сохранены. Глобальные правила безопасности/модели не изменяются.
Регрессионный тест использует настоящий `gateway_chat.validate_options`,
а не только проверяет отсутствие строк. Прежние остановленные задания не
переисполняются массово; неоднозначные записи/отправки не повторяются.
