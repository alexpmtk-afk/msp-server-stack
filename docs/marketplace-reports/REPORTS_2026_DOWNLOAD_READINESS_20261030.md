# МСП — готовность к исторической загрузке WB/Ozon 2026

30.10.2026, ChatGPT. PR #98 — отдельная офлайн-подготовка реальной загрузки. Приоритет: получить отчёты, а не продолжать мелкие циклы защиты B7.

## Подтверждено кодом репозитория

- 3 WB кабинета: wb_laser_master, wb_novokshenov, wb_dmitrieva. 3 Ozon кабинета: ozon_laser_master, ozon_novokshenov, ozon_dmitrieva.
- Реализованы одиночные read-only действия ingest.py: wb-list (обнаружить reportId), wb-one (детализация по ID/типу), ozon-final-one (закрытый месяц), ozon-current (FBO/FBS + начисления текущего месяца). Рабочая автоматическая выгрузка всего 2026 года пока не реализована.
- Старый и версионированный архивы разделены и не допускают штатную совместную запись одной области. B7 этапы 1–3 приняты Гермесом по своим офлайн-границам, но не слиты в main и не развёрнуты.
- Runtime имеет обязательную проверку общей очереди MSP_REPORTS_SHARED_QUEUE_VERIFIED=YES и фактическое резервирование Redis. P01 (совместный namespace/лимиты) НЕ подтверждён. Самовольное включение флага запрещено.
- В quota.py для WB list/detail есть консервативное правило общей очереди, но для всех Ozon finance endpoints функция request_rules прямо возвращает отказ «finance endpoint rate contract not yet approved». Значит Ozon нельзя считать готовым даже при будущем подтверждении одной общей Redis очереди — требуется отдельно принять лимиты конкретных методов.
- Полученные ранее сведения о CABINETS_VALID=6 и HTTP=200 для отдельных методов WB доказывали лишь доступность отдельных запросов, не историю 2026 и не полноту всех источников.

## Что добавлено в PR #98

- WB discovery wb-list выдаёт reportId, reportType, dateFrom, dateTo для каждой найденной записи; не выводит денежные поля. Это метаданные, не скачанные отчёты.
- Новый offline backfill_plan.py читает только локальные данные и заранее сохранённые результаты wb-list. Создаёт подробную очередь задач по всем 6 кабинетам и 2026 году, отдельно WB main/buyout, закрытые месяцы Ozon FINAL, текущие месячные Ozon FBO/FBS/accruals.
- Нет WB discovery => DISCOVERY_REQUIRED, а не 0 отчётов. Пустой список => SOURCE_EMPTY_UNCONFIRMED. Найденный локальный отчёт => LOCAL_VERIFIED_NOT_PROVIDER_COMPLETE. Повреждённый/смешанный архив => REVIEW_ARCHIVE. Результат никогда не объявляет COMPLETE.
- Запуск инструмента: python -m apps.msp_marketplace_reports.backfill_plan --root <изолированный локальный путь> --year 2026 --as-of 2026-10-30. Опционально --wb-inventory-json <локальный JSON>, сопоставляющий ID каждого WB кабинета с полным JSON-выводом wb-list. Никаких токенов в файле не нужно.
- На 30 октября 2026 закрытые месяцы Ozon FINAL: январь–сентябрь (9 на кабинет, всего 27 потенциальных проверок/задач). Текущий октябрь — отдельные 3 набора данных на кабинет (ещё 9). WB без обнаружения даёт три отдельные задачи discovery. Эти 39 задач являются планом при ПУСТОМ тестовом корне, а не реальным количеством пропусков на сервере.
- Данные из production, существующие архивы на VPS и текущая очередь здесь НЕ инспектировались. Статус фактической полноты 2026 остаётся UNKNOWN.

## Крупные работы, чтобы быстрее получить данные

1. Hermes отдельно, только read-only code/docs, выясняет, можно ли повторно использовать работавшую на старом сервере цепочку: точные методы, формат, правила докачки и реально готовые части системы. Без просмотра токенов, самостоятельного запуска API, SSH, Redis, workflow и настройки флагов.
2. Hermes исследует P01 namespace/atomic quota contracts существующего Marketplace MCP по источникам/коду и отдельно список лимитов Ozon finance methods. Возвращает чёткую матрицу VERIFIED / NOT VERIFIED и список минимальных условий для *разрешённого* малого live-теста.
3. ChatGPT независимо реализует план полного периода и безопасный механизм возобновляемой докачки на локальных искусственных данных; не включает API до отдельного разрешения. Проверка источников должна идти параллельно, не ждать следующей стадии B7.
4. После отдельного разрешения и проверки квот: минимальная реальная выборка, независимое сопоставление, затем годовая загрузка по шести кабинетам. Не обещать сроки до подтверждения внешних зависимостей.
