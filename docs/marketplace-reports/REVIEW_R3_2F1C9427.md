### Унаследованное замечание J1 — повторяющиеся JSON keys (не блокирует scoped R3)

Обе версии принимают manifest, в котором вместо `"schema": 1` записано `"schema": true, "schema": 1`: json.loads сохраняет последнее значение. verify=True, повторный импорт разрешён. Это НЕ обход проверки типа уже разобранного поля (последнее значение int), но неоднозначный контрольный документ не отклоняется. Для будущего строгого формата/журналов B7 рекомендуется общий decoder с `object_pairs_hook`, отклоняющим дубли, и явной политикой NaN/Infinity, с тестами до записи. Не объявлять этим дополнительным тестом существующие архивы повреждёнными без согласованного контракта. Это не R3 FAIL и не регрессия исправления.
