Денежные строки читаются через Decimal. Идентификаторы — строки без потери цифр. Булевы значения в CSV записаны как true/false: Python True/False здесь нельзя сравнивать текстом. Пустое значение, отсутствующая колонка, null и явный ноль различаются.

`rrDate` — дата операции в отчёте; `saleDt` — дата продажи/возврата или иной операции согласно её виду; `orderDt` — дата заказа. Период отчёта хранится в dateFrom/dateTo. Для фильтра периода всегда называть роль даты.

Критические соответствия: deliveryService — денежная логистика, deliveryAmount/returnAmount — количества доставок, paymentProcessing — текстовый тип платежа, acquiringFee — денежная плата. commissionPercent — кВВ; kvwBase/kvw — кВВ без НДС. dlvPrc — фиксированный коэффициент склада; warehouseLogisticsCoeff — другой коэффициент доставки. ppvzSupplierInn/Name относятся к партнёру ПВЗ, не определяют кабинет продавца. paymentSchedule описан WB как плата за изменение срока перечисления; значение -1 сохранять со знаком, не превращать в дату.

В стандартной проверке price × (1 − commissionPercent/100) − acquiringFee найдены четыре исключения. Использовать фактический forPay, не восстанавливать его по формуле. Статистика проверок — schema-profile.json; исходные суммы не изменялись. Причина исключений не установлена.
