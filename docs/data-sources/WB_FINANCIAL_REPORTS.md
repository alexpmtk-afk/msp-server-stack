# Единый вход: финансовые отчёты Wildberries

При вопросах о выручке, возвратах, комиссии, логистике, хранении, удержаниях,
кешбэке, перечислении/выплате, daily/weekly или полноте отчётов WB:

1. Определить кабинет, период и показатель; не путать отчёт по выкупам WB с самовыкупами.
2. Выполнить `msp-wb-report-guide route 'вопрос' --json`.
3. Читать [полную логику](wb-financial-reports/GUIDE.md), затем нужное поле/формулу.

- Машиночитаемая онтология: [ontology.json](wb-financial-reports/ontology.json).
- CLI без зависимостей: [guide.py](wb-financial-reports/guide.py); `field`, `formula`, `locate`, `sources`, `validate`, `calculate`.
- Навык: `apps/hermes/wb_financial_reports_skill/SKILL.md` (установлен в default-профиле Hermes и локальном Codex).
- Оперативные заказы: [APPROVED_REPORTS.md](APPROVED_REPORTS.md), не подменять их реализацией.

Это справочник для агентов и программ, не новый загрузчик или источник полномочий.
Архив: `/opt/mcp/data/msp-marketplace-reports`; существующие права доступа сохраняются.
Документация доступна процессам с правом читать проект. Сервисам в другом UID/контейнере
нужно явно подключить этот справочник/JSON разрешённым способом; наличие файла не заставляет
произвольное приложение автоматически учитывать семантику.
