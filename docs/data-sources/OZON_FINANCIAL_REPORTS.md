## Чтение и смысл

Одинаковые источники для панели Hermes, TUI и разрешённых Telegram-чатов
одного default-профиля. Это не автоматическое слияние историй/разрешений чатов.
Не искать случайные файлы на Drive и не запрашивать root для чтения уже
открытых финансовых файлов. Исходники не менять и повторно не скачивать ради анализа.

Метод `/v1/finance/realization/posting` отдаёт месячную реализацию по отправлениям.
Это не список заказов, не все начисления/логистика/реклама, не банковская выплата
и не прибыль. `delivery_commission`/`return_commission` — структуры реализации;
не трактовать их название как полный расход доставки без справочника формул.
Сначала изучить фактические вложенные поля `item`, `order`, `delivery_commission`,
`return_commission`, `legal_entity_document`; не терять их при чтении CSV.
CSV UTF-8-BOM, разделитель `;`, вложенные JSON сохранены плюс `_raw_json`.
Ключ: кабинет + report_year + report_month + row_number. Номера строк не являются
уникальными между месяцами/кабинетами. SKU/артикулы читать как строки.
Валюта и шапка документа находятся в исходном response.json, не угадывать их.

## После пакетной загрузки

Исходные месяцы: `/opt/mcp/data/msp-marketplace-reports/ozon-final-2026/CABINET/2026-MM/`.
Канонические месячные и годовые снимки:
`/opt/mcp/data/msp-marketplace-reports/.b7-generations/ozon_final_realization/CABINET/2026/`.
Брать согласованный CURRENT-снимок через `generation_store.read_active` и
`versioned_archive.read_csv_versioned`, не складывать поколения и не подбирать
случайную папку generations. Модули — `apps/msp_marketplace_reports/` в root_release
из проверенной корневой квитанции прогресса (путь программы root-owned/read-only).
В active['files'] находятся `monthly/2026-MM.csv` и `annual.csv`.
Квитанции отдельного месяца содержат generation и published_manifest_sha256;
для фиксированного снимка читать именно это поколение с проверкой digest.
Не складывать annual с monthly. Пропущенный/пустой/ошибочный месяц не считать нулём.
Текущий ноябрь и daily WB этим сбором не загружаются. Общая сверка колонок/формул
Ozon ещё не объявлена завершённой; суммы на основе неподтверждённых формул не считать.
